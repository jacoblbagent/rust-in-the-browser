The fractal benchmark

Each pixel runs an escape-time loop, up to 320 iterations of complex multiplication, and takes its colour from how long it took to escape. The same arithmetic runs three times: compiled from Rust two pixels at a time, compiled from Rust one pixel at a time, and written out as JavaScript below. All three fill an RGBA buffer of 720 by 540 pixels, and the page compares the output byte for byte.

Expect the scalar kernel and the JavaScript to land close together. This loop is a dependency chain of f64 multiplies, which is the shape of code a just-in-time compiler handles best. The two-lane kernel is where the gap opens: WebAssembly has vector instructions, and JavaScript has no way to reach them.

A disc of bodies under gravity

Each body is pulled toward a central mass by an inverse-square force and integrated with a symplectic Euler step. Rust holds the positions, runs the integration, writes the vertex buffer and issues the draw call. WebGL2 renders the bodies as additive point sprites, coloured by distance from the centre, so the core reads hot cream and the outer disc falls away through amber into rust.

A million cells, stepped in Rust

Conway's Game of Life on a 1,200 by 900 grid with wrapping edges. Every generation counts eight neighbours for each of the 1,080,000 cells. Rust steps the grid and paints the result into an RGBA buffer; a cell that has just died is left behind as a cooling ember, which shows where the activity has moved.

A surface built from scratch

A (2,3) torus knot: a circular tube swept along a curve that winds twice around one axis and three times around the other. Rust generates the vertices, carries a parallel-transport frame along the curve so the tube never pinches, builds the index buffer, and shades it with a key light, a fill and a rim. Depth testing and back-face culling are on. There is no 3D engine in the build.

The inner loops

Three versions of the escape-time loop that the benchmark times. The JavaScript is written to mirror the scalar Rust kernel statement for statement; the vector kernel has no JavaScript equivalent.

Rust, src/mandel.rs, scalar

let (mut zr, mut zi) = (0.0f64, 0.0f64);
let (mut zr2, mut zi2) = (0.0f64, 0.0f64);
let mut i = 0u32;
while i < max_iter && zr2 + zi2 <= 4.0 {
    zi = 2.0 * zr * zi + ci;
    zr = zr2 - zi2 + cr;
    zr2 = zr * zr;
    zi2 = zi * zi;
    i += 1;
}

Rust, src/mandel.rs, two-lane

let mut counts = i64x2_splat(0);
let mut done = i64x2_splat(0);
while k < max_iter {
    zi = f64x2_add(f64x2_mul(f64x2_mul(two, zr), zi), civ);
    zr = f64x2_add(f64x2_sub(zr2, zi2), crv);
    zr2 = f64x2_mul(zr, zr);
    zi2 = f64x2_mul(zi, zi);
    let mag = f64x2_add(zr2, zi2);
    counts = i64x2_add(counts, v128_andnot(one, done));
    done = v128_or(done, f64x2_gt(mag, four));
    if i64x2_all_true(done) { break; }
    k += 1;
}

JavaScript, www/app.js

let zr = 0, zi = 0;
let zr2 = 0, zi2 = 0;

  zi = 2 * zr * zi + ci;
  zr = zr2 - zi2 + cr;
  zr2 = zr * zr;
  zi2 = zi * zi;
  i++;
